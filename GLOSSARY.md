# Portfólio de Felipe Levi

Termos específicos dos projetos apresentados no portfólio.

## Linguagem

**Harmony**:
Design system da CASSI, adotado como base dos novos projetos e incorporado gradualmente aos produtos existentes. É um sistema em evolução contínua, mantido em colaboração entre design e desenvolvimento.
_Evitar_: projeto encerrado, migração concluída de todo o ecossistema.

**CASSI Convênios**:
Aplicativo da CASSI para participantes de reciprocidade, criado antes do Harmony e com biblioteca e linguagem visual próprias. É um produto anterior à direção visual adotada pelo Harmony.
_Evitar_: produto construído sobre o Harmony, variante visual do Harmony.

**Percurso no portfólio**:
Sequência de navegação de uma pessoa pela home e pelos estudos de caso durante uma mesma visita. Pode abranger várias páginas sem se tornar uma visita independente em cada uma.
_Evitar_: tratar uma visualização isolada de página como o percurso completo.
