# Billing decision icons

Official, unmodified Tabler outline SVGs: `shield-lock.svg` for verified access and `clock.svg` for the self-service design target. The shared `../components.svg` is reused for maintaining a shared flow.

Source: [tabler/tabler-icons, outline icons](https://github.com/tabler/tabler-icons/tree/a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d/icons/outline), pinned commit `a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d`.

Downloaded from the matching `raw.githubusercontent.com/tabler/tabler-icons/<commit>/icons/outline/` URLs on 2026-10-24. The upstream MIT license remains in [../LICENSE](../LICENSE), unchanged. CSS masks use the existing accent token. Icons are decorative (`aria-hidden="true"`) and accompanied by accessible text.
