# Enrollment decision icons

Unmodified official Tabler outline SVGs: `lock-open` (exploration before registration), `route` (sequence of steps), and `list-check` (proposal progress).

Source: https://github.com/tabler/tabler-icons/tree/a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d/icons/outline

Each file was downloaded from `https://raw.githubusercontent.com/tabler/tabler-icons/a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d/icons/outline/<name>.svg` on 2026-10-24. The shared MIT license remains in [../LICENSE](../LICENSE).

The local Enrollment stylesheet applies the existing accent color through CSS masks. Icons are decorative; adjacent text conveys each message.
