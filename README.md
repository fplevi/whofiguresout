# Felipe Levi — Portfolio

Personal portfolio built entirely with AI assistance. Every layer of the project — from concept to code — was made in collaboration with AI tools.

---

## How this was made

This project started as an experiment: could I build a production-quality portfolio end-to-end using only AI tools, without writing a single line of code by hand?

The answer was yes.

**Ideation and structure** were defined with Claude. The information architecture, section order, content hierarchy, and copywriting all came out of conversations — not a brief handed to a developer.

**The first round of layouts** was built in Figma by Claude through the Figma MCP: sketches, high-fidelity frames, components, spacing, and visual language.

**After that, design moved into the code.** Every later design decision — layout, type scale, image treatment, interactions — was made directly on the live site by Claude Code (Anthropic's CLI), iterating and checking each change against rendered screenshots at real viewport widths. Decisions worth keeping are recorded as ADRs in `docs/adr/`.

**The code** — every HTML file, every CSS rule, every JavaScript interaction — was written by Claude Code. No template was used. The site grew incrementally, one deliberate change per commit.

**The profile photo** was generated with ChatGPT. Case study screens are real product material.

---

## Key decisions

**No framework, no build step.** The site is plain HTML, CSS, and vanilla JS. Fast to load, easy to maintain, zero dependencies.

**Design tokens as the foundation.** All spacing, typography, color, and radius values live in `tokens.css`. Every component references them — consistency is structural, not manual.

**Scroll animations without a library.** Entrance animations, nav fill-on-scroll, and the photo parallax effect are all driven by `IntersectionObserver` and `requestAnimationFrame` — no GSAP, no ScrollTrigger.

**Before/after comparison slider built natively.** The enrollment case study uses a `clip-path` approach driven by a range input — no third-party slider library.

**Responsive images.** Content images are served as AVIF with WebP fallback, generated by `scripts/image-variants.py` (see `docs/agents/images.md`).

**Semantic, accessible HTML.** ARIA labels, landmark roles, skip links, and reduced-motion support are built in from the start — not retrofitted.

**Recorded decisions** (ADRs, in Portuguese):

- [0001](docs/adr/0001-preservar-analytics-na-otimizacao-lighthouse.md) — Lighthouse optimization keeps Clarity and GA4 session continuity across pages.
- [0002](docs/adr/0002-so-controles-tem-cantos-arredondados.md) — Only interactive controls have rounded corners; content surfaces are square.
- [0003](docs/adr/0003-pagina-congela-em-1920px.md) — The page stops growing at 1920px; wider screens only extend the background.
- [0004](docs/adr/0004-imagens-dos-cases-em-meia-coluna.md) — Case images sit in 50/50 text|image rows, uncropped and unzoomed.

Domain terms used across the cases live in `GLOSSARY.md`.
